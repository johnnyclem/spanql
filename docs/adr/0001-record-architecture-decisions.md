# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-17

## Context
spanql is in a design phase with several load-bearing choices (model/engine split, storage, language, packaging) that will be revisited as evidence comes in.

## Decision
Record significant decisions as ADRs in `docs/adr/`, numbered, with Status (Proposed / Accepted / Superseded), Context, Decision, Consequences. Proposed ADRs become Accepted at design sign-off (Roadmap M0) or when evidence (eval results) supports them.

## Consequences
Reversals are cheap to document: write a new ADR that supersedes the old one.
